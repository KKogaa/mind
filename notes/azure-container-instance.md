Azure Container Instances (ACI) is the service that allows you to deploy  a container on Azure cloud without having to manage the underlying infrastructure. ACI allows you lauch containers quickly. With ACI you incur costs only when running the container. The billing is on a per-second insted of a per minute billing. You can isolate an application in a container like VM environment. You can specify custom sizes for an Azure Container by specifying exact values for CPU cores and memory. Wit ACI, you can mount Azure files for persistent storage. The shared files are part of the container and are in a persistent state. You can have scheduled Linux containers as well as Windows containers with the same API. ACI allows to have Hypervisor-level security which can isolate your application like the same experience that occurs in a VM.

ACI Features
- Fast startup
- Custom sizes
- Persistent storage
- Per second billing
- Hypervisor-level security
- Linux and Windows
Azure Kubernetes Service Features 
- Full container orchestration
- Service discovery across multiple containers
- Automatic scaling
- Coordinated application upgrades
