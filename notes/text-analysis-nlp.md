# Text Analysis (NLP)

Using AI to extract meaning and insights from written text. One of the workloads in [[ai-workloads]]; delivered on Azure by the Language tool listed in [[microsoft-foundry]].

## Unstructured text sources

- Emails.
- Product reviews.
- Documents.
- Tweets.
- Scientific papers.

## Techniques

- **Keyword extraction** — highlight the important keywords in a text.
- **Entity detection** — extract names, locations, dates, organizations.
- **Sentiment analysis** — classify text as positive, negative, or neutral, e.g. over product reviews.
- **Summarization** — condense long text.

In a production environment you'll typically **combine** several of these rather than using one in isolation.
